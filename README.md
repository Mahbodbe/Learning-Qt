## 🌐 English Version

### 📌 About This Repository
This repository documents my personal journey and hands-on practice in learning **Qt C++ GUI Framework** and **Qt Creator**. 

It contains code samples, structured exercises, and projects derived from:
1. **Primary Reference Book:** *Getting Started with Qt 5* written by **Benjamin Baka**.
2. **AI-Guided Exercises:** Custom exercises generated by AI assistants to practice specific framework concepts (such as working with Qt Creator Wizards, Signals & Slots, Layout Managers, Widgets, and Custom Controls).

> [!NOTE]
> While a portion of the codebase follows the book's structured chapters, it is not strictly limited to it. It also includes extra practice tasks and standalone experiments (e.g., my initial wizard-driven exercise in the `first` directory).

### 🚀 Getting Started

#### Prerequisites
- **Qt Creator** (v4.x / v10.x or newer)
- **Qt Framework** (Qt 5.x / Qt 6.x)
- **C++ Compiler** (GCC / Clang / MSVC)
- **QMake** or **CMake**

#### Building & Running
1. Clone the repository:
   ```bash
   git clone https://github.com/Mahbodbe/Learning-Qt.git
   ```
2. Open **Qt Creator**.
3. Select `File -> Open File or Project...` and open the `.pro` or `CMakeLists.txt` file from any exercise folder (e.g., `first/first.pro`).
4. Click **Configure Project**, then press `Ctrl + R` (or click the green **Run** button) to build and run.
